# Trúc Xanh - Game lật thẻ ghép cặp (Windows Forms, .NET Framework 4.8)

## Cách chạy
1. Clone repo, mở `UI Design.csproj` bằng Visual Studio.
2. Build -> Rebuild Solution, rồi nhấn F5.
3. Bấm BẮT ĐẦU, ghi nhớ vị trí thẻ rồi ghép cặp trong 90 giây.

## Tính năng
- Xáo trộn thẻ bằng Random, so sánh cặp, Timer úp thẻ và đếm ngược.
- Nhạc nền bằng SoundPlayer (.wav), bật/tắt từ menu.
- Lưu thành tích vào thanhtichs.txt, xem Bảng Thành Tích.
- Bẫy lỗi try...catch khi thiếu tài nguyên.
